Emulation Guides.

Getting Started on Windows

Windows has the widest emulator support. Most emulators ship as pre-built .exe files, no installation required in many cases.
All game files (ROM, iso, etc.) should be obtained through legal methods, using games you already own.

Step 1 — Install Visual C++ Redistributables

  1. Download the latest Microsoft Visual C++ Redistributable from Microsoft's official site.
  2. Install both the x64 and x86 versions many, emulators require both.
  3. Restart your PC if prompted.

Step 2 — Download an Emulator

  1. Choose a system to emulate (e.g. SNES, PS2, GBA) and find the appropriate emulator.
  2. Always download from the emulator's official website or GitHub releases page.
  3. Extract the .zip or .7z archive to a permanent folder (e.g. C:\Emulators\).

Step 2 [Alternative] — Download RetroArch

  1. RetroArch is a one size fits all emulator available on Steam and their website.
  2. This method is easier, as it removes the requirement of installing several applications, especially as the steam installation makes the process as easy as clicking install.

Step 3 — Configure & Load a ROM

  1. Launch the emulator .exe and open its Settings or Configuration menu.
  2. Point the emulator to your BIOS folder if required (e.g. PS2/PS1 need a BIOS dump from your console).
  3. Use File → Open ROM (or equivalent) to load your game file.
Windows Defender may flag emulators as suspicious. If you trust the source, add the emulator folder to Defender's exclusion list via Windows Security → Virus & threat protection → Exclusions.

Getting Started on macOS

macOS support varies. Apple Silicon (M1/M2/M3) Macs run emulators natively or via Rosetta 2. Most emulators are distributed as .dmg or .app bundles.

Step 1 — Allow Apps from Unidentified Developers

  1. Open System Settings → Privacy & Security.
  2. Under Security, set Allow apps downloaded from to App Store and identified developers.
  3. After launching a blocked app once, a new "Open Anyway" button will appear in this same menu.

Step 2 — Remove Quarantine (if needed)

  1. If macOS still blocks the app, open Terminal.
  2. Run: xattr -cr /Applications/YourEmulator.app
  3. This removes the quarantine flag applied to downloaded files.

Step 3 — Download & Run

  1. Download the .dmg from the emulator's official site.
  2. Open the DMG and drag the .app to your Applications folder.
  3. Launch, configure controllers, and load your ROM.
Apple Silicon users: check whether the emulator has a native ARM build before defaulting to Rosetta 2, native builds are significantly faster.

Getting Started on Linux

Linux offers excellent emulator support. Most emulators are available via your distro's package manager, Flatpak, or as AppImages.

Step 1 — Choose Your Install Method

  • Flatpak (recommended) — sandboxed, distro-agnostic, always up-to-date.
  • Package manager — apt, pacman, dnf etc. Quick but may be outdated.
  • AppImage — portable single-file binary, no install needed.

Step 2 — Install via Flatpak (Example)

  1. Ensure Flatpak is installed: sudo apt install flatpak
  2. Add Flathub: flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
  3. Install an emulator, e.g. RetroArch: flatpak install flathub org.libretro.RetroArch

Step 3 — Controller & Permissions

  1. Most controllers work out of the box via udev. If not, add your user to the input group: sudo usermod -aG input $USER
  2. Log out and back in for group changes to take effect.
  3. Launch the emulator and configure your input bindings.
Flatpak apps run in a sandbox. If your emulator can't see your ROMs folder, grant access with: flatpak override --user --filesystem=~/ROMs org.libretro.RetroArch

Getting Started on Steam Deck

The Steam Deck runs a Linux-based OS (SteamOS). Emulators can be installed in Desktop Mode via the Discover store (Flatpak) or via EmuDeck, a one-click setup script.

Option A — EmuDeck (Recommended for Beginners)

  1. Switch to Desktop Mode: hold the Power button → Switch to Desktop.
  2. Open a browser and go to emudeck.com, download the installer script.
  3. Run the installer — it will configure emulators, Steam ROM Manager, and controller profiles automatically.
  4. Copy your ROMs to the designated folders on your SD card or internal storage.
  5. Use Steam ROM Manager to add games to your Steam library and return to Game Mode.

Option B — Manual Flatpak Install

  1. In Desktop Mode, open Discover (the shopping bag icon).
  2. Search for your emulator (e.g. RPCS3, Dolphin, PPSSPP).
  3. Install and launch from the Desktop to configure settings before returning to Game Mode.
Set the per-game performance overlay to check frame rate. Most 16-bit era games will run at full speed on default settings — only demanding systems like PS3 or GameCube may need manual tweaking.

Getting Started on Android

Android has robust emulator support. Many excellent emulators are free on the Play Store; others are paid or require sideloading an APK.

Step 1 — Enable Unknown Sources (for APK installs)

  1. Go to Settings → Apps → Special App Access → Install Unknown Apps.
  2. Enable the toggle for your browser or file manager.
  3. This only needs to be done once for sideloaded emulators.

Step 2 — Download an Emulator

  • Play Store: Search for emulators like Delta, Lemuroid, or RetroArch.
  • APK (sideload): Download from the official GitHub releases page of the emulator. Avoid third-party APK mirror sites.

Step 3 — Add ROMs & Play

  1. Copy ROM files to your device via USB, cloud storage, or a local network share.
  2. Open the emulator and point it to your ROM directory.
  3. For touch controls, configure the on-screen overlay in the emulator's settings. A Bluetooth controller is strongly recommended for comfort.
Pair any Bluetooth gamepad (Xbox, PlayStation, 8BitDo) for a vastly better experience. Android natively supports most modern controllers without additional apps.
